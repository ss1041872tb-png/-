# 中和食光 · 彎巷闖關冒險 v2.1

繁體中文 3D 微縮街區。十家店散落於彎折巷道、四種朝向與四個小街區，保留原有店名、地址、文案、推薦餐點與 Google Maps 導航。場景與小地圖皆為虛構配置，並非真實地理位置；橋壽司位於永和區。

## 啟動與公開網站

```sh
cd /workspace/-
python -m http.server 8000 --bind 127.0.0.1
```

以現代瀏覽器開啟本機 HTTP 服務；原始 `index.html` 不能直接用檔案方式載入相對 ES modules。引擎、樣式、遊戲、3D 餐點與音效皆在專案內，遊玩不需外部 API 或 CDN。Google Maps 導航另需網路。公開版本使用 GitHub Pages 的 `gh-pages` 分支；原始碼在 `codex/zhonghe-food-explorer` 分支。尚未通過驗證的本地修改不會自動發布。

## 玩法

1. 按「出發，走進巷弄」，用 WASD／方向鍵移動；手機按住虛擬方向鍵。方向依當下鏡頭計算：前進朝畫面前方，左右朝畫面兩側；主角頭頂的三角標記在建築遮擋時仍可辨識。道路有行駛中的汽車、機車，接近玩家會停讓。NPC 包含學生、上班族、遊客與店員。
2. 用小地圖指定店家，走到店前金色路標；按 **E**、手機情境按鈕或店前路牌開始任務。遠處點招牌、護照或地圖只能指定目的地，不能隔空闖關或集章。
3. **每家三關，共 30 關**。已完成的關卡自動保存，未完成的小遊戲離開後重新開始。失敗可重試，沒有付費、次數或倒數限制。
4. 每家第三關完成會出現通關橫幅、煙火粒子、原創合成樂句與歡呼音效；靜音時不發聲，減少動態時只顯示靜態橫幅。三關完成才會打開柵欄與橋面；親自過橋、抵達店前，再點立體招牌或情境按鈕，才會開啟資訊卡並收藏唯一徽章。
5. 集滿十枚徽章與三十關，在護照中查看「巷弄冒險家」完成畫面。可在護照確認後重新開始；角色會回到街區入口，避免被重新關閉的柵欄困住。

滑鼠／單指拖曳旋轉視角，滾輪／雙指開合縮放。「重設視角」回到總覽與街區入口，不會清除進度。進度保存在 `zhonghe-alley-adventure-v2`；舊版 `zhonghe-food-passport-v1` 保留，但舊徽章不會直接解鎖新版關卡。

## 六種小遊戲

| 遊戲 | 規則 |
| --- | --- |
| 搬積木・搭小橋 | 拿取三種積木、旋轉至指定角度，再放進相同顏色的橋墩；不能空手放置或放錯方向。 |
| 街角猜拳王 | 對手在出拳時隨機選擇，累積贏兩次；落敗、平手可繼續。 |
| 九宮格滑塊 | 數字 1–8 依序排列，空格在右下角；初始盤面由完成盤面合法打亂，保證有解。 |
| 美食翻翻樂 | 翻開八張牌、配對四組美食；配錯會蓋回，可記住位置繼續。 |
| 主廚配餐記憶 | 先看四步食譜，按「我記好了」後按順序配餐；可重新查看食譜。 |
| 巷口井字棋 | 你是 ○、守門員是 ×；獲勝或平手皆通過，落敗可重來。 |

不同店家交錯安排三種關卡，橋墩角度、滑塊盤面、卡片位置與食譜也依店家不同。沒有「跳過」按鈕，護照與導航不會直接加進度。

## 音效、效能與操作設定

首次真實操作才啟用 Web Audio，不會載入頁面就自動播放。提供腳步、按鍵、積木、失敗、過關、解鎖、徽章與近處引擎音效；均為程式合成，沒有外部音訊或音樂授權需求。可在右下角靜音，或在玩法設定調整音量。所有關卡均有視覺與文字回饋，不依賴聽力。

省電模式降低像素比至 1、關閉陰影、限制每秒最多更新 30 次；減少動態預設尊重系統偏好，停下 NPC、車流與人物擺動。靜態街景使用共用幾何、材質與 InstancedMesh 合批，彎道使用連續帶狀幾何避免重疊閃爍。瀏覽器軟體 WebGL 測試不能當成實機手機 FPS。

## 原創 3D 餐桌

依最新需求，十家店的資訊卡改用程式建模的立體餐點：麻醬麵、涼麵、蛋餅燒餅、烤餅咖哩、米糕、鍋貼、握壽司、打拋飯、米粉湯與串燒。包含麵條、米粒、煎烤痕、配料、陶瓷器皿、材質與打光，可拖曳或按旋轉按鈕欣賞。清楚標示「原創 3D 餐點示意・非店家實拍」，不代表店家實際擺盤或份量。

模型與紋理皆由專案程式產生，未使用第三方食物照片。資訊卡共用一個額外 WebGL renderer，僅在開啟、旋轉或尺寸改變時繪製；更換餐點時釋放舊幾何與材質。低階裝置無法建立模型視窗時，使用同一原創模型預先算圖的本地 PNG，不影響店家文字資料。`python scripts/render-food.py` 可在本機服務啟動後重建十張備援圖片。

## 測試

```sh
python tests/smoke.py
# 等同 python tests/adventure.py
python tests/food.py
python tests/standalone.py  # 先執行單檔打包
```

使用環境既有 Python Playwright 與 `/usr/bin/chromium`，可用 `EXPLORER_URL` 指定另一個 HTTP 根網址。新版驗收也檢查四個鏡頭角度及真實滑鼠旋轉後的移動、主角標記、十店慶祝、十款可旋轉模型及手機大字提示。驗收會實際操作全部三十關的按鈕，包含輸入錯誤、重試、部分進度保存、鎖定區碰撞、真實跨橋與十店招牌點選；不直接呼叫 `campaign.complete()` 代替遊戲。另檢查車流、音效狀態、靜音保存、重置、手機方向鍵／雙指縮放／關卡焦點／直橫向與引擎載入失敗時的唯讀店家預覽。`?test` 只供測試時開啟檢查介面。

## 打包

```sh
python scripts/package.py
python scripts/standalone.py
```

分別產生 `dist/zhonghe-food-explorer.zip`（部署包，含 SHA-256 清單與 MIT 授權）及 `dist/zhonghe-food-explorer-preview.html`（單檔預覽，內嵌引擎、所有遊戲與 3D 餐點）。部署包可解壓上傳至靜態主機。單檔版可下載後在一般 Chrome／Edge 開啟，不需 Python；受管理瀏覽器可能禁止本機檔案或 Blob 模組。聊天介面的封存檔檢視器並非互動瀏覽器。

## 模組

- `src/layout.js`：巷道、圓角路網、店家配置與座標轉換。
- `src/world.js`：街景、招牌、NPC、汽機車、實體柵欄／橋與碰撞。
- `src/campaign.js`：30 關配置、儲存驗證、解鎖與徽章規則。
- `src/challenges.js`：六種可操作小遊戲及生命週期。
- `src/sound.js`：需使用者啟用的合成音效、音量與靜音。
- `src/main.js`：距離判斷、互動入口、遊戲迴圈與錯誤處理。
- `src/controls.js`、`src/navigation.js`、`src/ui.js`：操作、指引、對話框與護照。
- `src/data.js`：原有店家資料。
- `src/food-models.js`、`src/food-view.js`：原創 3D 餐點、按需繪製與本地備援。
- `src/celebration.js`：通關煙火、橫幅與減少動態支援。
