# 中和美食探索 Zhonghe Food Explorer

這是 3D 微縮美食街互動導覽原型。入口：`index.html`。

## 本機開啟
請使用 VS Code Live Server 或執行 `python -m http.server 8000` 後開啟 `http://localhost:8000`。Three.js 透過 CDN 載入，需要網路。

## 交接給 Codex
在 Codex 中開啟本資料夾，告知 Codex：「請先閱讀 AGENTS.md 和 README.md，檢查現有程式並完成第一階段測試修復。」

備註：橋壽司位於永和區。其餘店家資訊需在正式發布前再次核驗。現有場景不是真實街道測繪。
