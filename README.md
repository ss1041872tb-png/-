# 中和食光 · Zhonghe Food Explorer

繁體中文的 3D 微縮美食街區。保留原型的十家店資料、自由移動、招牌點選、店家資訊卡、Google Maps 導航與集章，升級台灣騎樓街景、NPC 動畫及桌面／手機介面。場景是虛構配置，**不代表真實地理位置**；橋壽司位於永和區，正式上線前仍須核對所有店家地址與營運資訊。

## 啟動

需要 Python 3 與支援 WebGL 的現代瀏覽器，無套件安裝或建置步驟；請以 HTTP 服務啟動，直接用 `file://` 開啟 HTML 無法載入 ES modules。

```sh
cd /workspace/-
python -m http.server 8000 --bind 127.0.0.1
```

於瀏覽器開啟本機 8000 埠。Three.js 0.160.1、美食插畫、樣式與程式皆隨專案內附，載入與遊玩不需連線到外部 CDN、字型或圖片服務。Google Maps 導航另需網路。引擎檔案缺少或 WebGL 不可用時會顯示提示與重試按鈕，美食護照仍能查閱店家。

## 操作

- **WASD／方向鍵**：沿世界方向移動旅人，建物與街道物件有碰撞限制。
- **滑鼠／單指拖曳**：旋轉視角；**滾輪／手機雙指開合**：縮放；**重設視角**：回到起點。雙指操作與取消手勢不會誤觸招牌。
- **手機方向鍵**：按住移動，放開即停止，支援指標捕捉與取消事件。
- **滑過招牌**：高亮與店名提示；**點選招牌**：右側開啟共用資訊卡並收集徽章。
- **街區小地圖**：點選編號設定目的地；金色路標標示店前位置，抵達後可用按鈕查看美食。設定目的地不會集章，收藏後會自動推薦最近的未探索店家。小地圖顯示虛構街區中的相對位置與方向，並非現實路線規劃；手機預設收合，可點標題展開。
- **美食護照**：查看十家店徽章，也提供鍵盤可用的店家選取方式。
- **玩法與設定**：查看操作說明、開關省電模式（像素比 1、關閉陰影、最多 30 次／秒更新）與減少動態（預設尊重系統偏好，暫停 NPC 和人物擺動）。設定會在目前瀏覽器保存。
- **Esc／關閉按鈕**：關閉資訊卡。開啟卡片時暫停玩家移動，鍵盤焦點保留在卡片內。

進度以 `zhonghe-food-passport-v1` 儲存於瀏覽器 localStorage；重新整理仍保留。可在美食護照選擇「重新開始探索」，確認後清除徽章；不會移除操作設定或網站其他資料。儲存遭封鎖時仍可完成當次探索，護照會提示進度可能無法保留。

## 程式結構

| 路徑 | 用途 |
| --- | --- |
| `index.html`、`styles.css` | 語意化介面、響應式樣式與載入狀態 |
| `src/data.js` | 原有十家店資料，單一資料來源 |
| `src/world.js` | Three.js 場景、可點選雙面招牌、角色、碰撞、NPC 路徑 |
| `src/controls.js` | 鍵盤、滑鼠、單指視角、雙指縮放與輸入清理 |
| `src/navigation.js` | 小地圖、下一站推薦、抵達判定與路標連動 |
| `src/ui.js` | 共用資訊卡、美食護照、集章持久化與焦點管理 |
| `src/main.js` | 非同步載入、遊戲迴圈與失敗處理 |
| `assets/*.svg` | 專案原創美食插畫；**非店家實拍**，介面亦有標示 |
| `vendor/` | 內附 Three.js、MIT 授權與完整性來源記錄 |
| `scripts/package.py` | 產生可部署 ZIP 與 SHA-256 檔案清單 |
| `tests/smoke.py` | 桌面／手機瀏覽器功能與多點觸控測試 |

靜態物件依幾何和材質使用 InstancedMesh 合批；共用低多邊形幾何、單一陰影光源及限制像素比，避免為視覺效果增加大量 draw calls。NPC 包含學生、上班族、遊客與店員，使用固定人行路徑、肢體擺動、漸進轉向與距離避讓。無額外後端服務或 API 金鑰需求。

## 測試

先啟動 HTTP 服務，再執行（使用雲端環境既有的 Python Playwright 與 `/usr/bin/chromium`）：

```sh
python tests/smoke.py
```

可用 `EXPLORER_URL` 覆寫測試位址。測試包含十店真實 3D 招牌點選、高亮、卡片／插畫／導航、十枚唯一徽章與成就、重新整理保存、鍵盤／虛擬方向鍵、拖曳／縮放、持續按鍵撞牆與停止動畫、NPC 路徑、失焦清理、焦點限制、手機直橫向無溢出、小地圖選點不集章／到店收藏／自動換站、真實雙指縮放與取消手勢，操作說明與設定保存、重置確認／取消、引擎檔案失敗降級、儲存停用及 WebGL 不可用時的替代操作。`?test` 僅供測試時啟用場景檢查介面，正常入口不暴露該介面。截圖輸出於 `/tmp/zhonghe-*.png`。

功能測試會攔截外部網路；應用程式只使用目前 HTTP 主機的資源。未把測試執行時的軟體 WebGL 渲染效能當成真實裝置 FPS。

效能仍取決於裝置 GPU，無頭軟體 WebGL 測試不能代表手機硬體的實際 FPS；正式發布前建議在真實手機再做體感及無障礙驗收。

## 打包與部署

```sh
python scripts/package.py
```

輸出 `dist/zhonghe-food-explorer.zip`。解壓後將內容上傳至支援 JavaScript modules 的靜態網站主機即可，無伺服器端程式、API 金鑰或建置服務需求；必須一併保留 `src/`、`assets/`、`vendor/` 目錄。可部署於網域根目錄或子目錄，連結使用相對路徑。先以解壓後資料夾啟動 HTTP 服務確認檔案完整，再發布至自己的主機；本地測試與交付部署包不代表已公開上線。

ZIP 附 `manifest.sha256.json` 可核對交付檔案。程式、插畫與第三方來源說明見 `CREDITS.md`；Three.js 的 MIT 授權保留在 `vendor/THREE-LICENSE.txt`。打包腳本會先核對引擎檔案 SHA-256，同一份來源重複打包會得到相同 ZIP。

## 不安裝 Python 的單檔預覽

```sh
python scripts/standalone.py
```

產生 `dist/zhonghe-food-explorer-preview.html`，包含樣式、程式、Three.js、MIT 授權及美食插畫。將這份 HTML 存到自己的電腦，用最新版 Chrome 或 Edge 開啟即可，不需要解壓整個網站或另外啟動 Python。這與仍需 HTTP 服務的原始 `index.html` 不同。

聊天介面的 ZIP／HTML 檔案檢視器不等於互動瀏覽器；請下載檔案後再開啟。若你的電腦由公司管理並禁止本機 HTML／Blob 模組，需改用原本的 HTTP 預覽或靜態網站部署方式。瀏覽器若不允許本機檔案儲存資料，仍可進行當次集章，進度保存會顯示提示。

`python tests/standalone.py` 驗證內嵌引擎、圖片、集章及鍵盤移動皆可在無外部請求的獨立文件中運作。雲端受管理瀏覽器封鎖 `file://`，因此測試使用不具網站來源的文件載入單檔內容，未宣稱已在此環境驗證直接雙擊檔案。
