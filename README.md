# 中和食光 · 巷弄店內尋寶 v3

繁體中文 3D 微縮街區。十家店散落於彎折巷道、四種朝向與四個小街區，保留原有店名、地址、文案、推薦餐點與 Google Maps 導航。場景與小地圖皆為虛構配置，並非真實地理位置；橋壽司位於永和區。

## 啟動與公開網站

```sh
cd /workspace/-
python -m http.server 8000 --bind 127.0.0.1
```

以現代瀏覽器開啟本機 HTTP 服務；原始 `index.html` 不能直接用檔案方式載入相對 ES modules。引擎、樣式、遊戲、3D 餐點與音效皆在專案內，遊玩不需外部 API 或 CDN。Google Maps 導航另需網路。公開版本使用 GitHub Pages 的 `gh-pages` 分支；原始碼在 `codex/zhonghe-food-explorer` 分支。尚未通過驗證的本地修改不會自動發布。

## 玩法：走進店裡尋寶

1. 用 WASD／方向鍵或手機虛擬方向鍵移動，滑鼠／手指拖曳轉視角。移動方向跟隨當下鏡頭，主角頭頂有三角標記。
2. 小地圖與尚未完成的收集格只能指定目的地。走到店門口自動出現任務，不需按招牌開始；繼續往店門走，就會切入可走動的 3D 店內場景。
3. **每店找兩件物品，共二十件。** 家具包含抽屜、書架、調味架、工作檯及收銀櫃，有碰撞與可走動的通道。走近家具，按 E、點擊家具，或按手機情境搜尋按鈕。搜尋無關家具不會獲得物品；遠處點擊也不能隔空收集。可用「給我線索」取得目前缺少物品的提示。
4. 找到第二件物品會自動播放煙火與慶祝樂句，招牌美食放大出現，再自動飛進收集箱。每店只獲得一份。獎勵在搜尋成功時立即保存，動畫中重新整理也不會丟失或重複給獎。
5. 可走回店內出口或按「離開店內」返回街區，未找齊的物品會保留。已收藏的餐點可從收集箱開啟 3D 展示、店家資料與 Google Maps。集滿十道美食即可獲得尋寶完成畫面。

新版存於 `zhonghe-room-hunt-v3`。舊版 v1 護照、v2 三關冒險資料與偏好設定保留，不會直接完成新版尋物。重設視角只回街區入口；收集箱的重新開始必須在介面確認，才會清除新版進度。

## 配樂、音效與效能

首次點擊或按鍵後才啟用原創循環背景音樂，包含輕柔旋律與低音伴奏；尋物與過關有合成音效、慶祝樂句與歡呼，無外部音檔。背景配樂可獨立開關，總靜音與音量同時控制音樂和音效。切換到其他分頁會停止配樂排程，返回後恢復，未互動前不會自行發聲。

省電模式降低解析度並限制每秒最多 30 次更新；減少動態設定停下 NPC／車流，慶祝保留靜態橫幅，獎勵省略飛行動畫。店內使用同一個街景 renderer，進出店清理家具與紋理，避免不斷增加 WebGL context。瀏覽器軟體 WebGL 測試不能當成實機手機 FPS。

## 原創 3D 餐桌

依最新需求，十家店的資訊卡改用程式建模的立體餐點：麻醬麵、涼麵、蛋餅燒餅、烤餅咖哩、米糕、鍋貼、握壽司、打拋飯、米粉湯與串燒。包含麵條、米粒、煎烤痕、配料、陶瓷器皿、材質與打光，可拖曳或按旋轉按鈕欣賞。清楚標示「原創 3D 餐點示意・非店家實拍」，不代表店家實際擺盤或份量。

模型與紋理皆由專案程式產生，未使用第三方食物照片。資訊卡共用一個額外 WebGL renderer，僅在開啟、旋轉或尺寸改變時繪製；更換餐點時釋放舊幾何與材質。低階裝置無法建立模型視窗時，使用同一原創模型預先算圖的本地 PNG，不影響店家文字資料。`python scripts/render-food.py` 可在本機服務啟動後重建十張備援圖片。

## 測試

```sh
python tests/smoke.py
# 等同 python tests/adventure.py
python tests/food.py
python tests/standalone.py  # 先執行單檔打包
```

使用既有 Python Playwright 與 `/usr/bin/chromium`；`EXPLORER_URL` 可指定 HTTP 根網址。`tests/hunt.py` 實際以鍵盤走過十家店的門口與店內家具通道、搜尋二十件物品，驗證隔空點擊無法獲得物品、獎勵自動飛入收集箱、部分儲存、重訪、重設、配樂與手機操作。測試可定位到各店外街道，店內路徑由真實方向鍵行走，沒有直接呼叫 `campaign.find()` 取代搜尋。

## 打包

```sh
python scripts/package.py
python scripts/standalone.py
```

分別產生 `dist/zhonghe-food-explorer.zip`（部署包，含 SHA-256 清單與 MIT 授權）及 `dist/zhonghe-food-explorer-preview.html`（單檔預覽，內嵌引擎、所有遊戲與 3D 餐點）。部署包可解壓上傳至靜態主機。單檔版可下載後在一般 Chrome／Edge 開啟，不需 Python；受管理瀏覽器可能禁止本機檔案或 Blob 模組。聊天介面的封存檔檢視器並非互動瀏覽器。

## 模組

- `src/layout.js`、`src/world.js`：虛構彎巷、街景、招牌、NPC 與汽機車。
- `src/campaign.js`、`src/interior.js`：二十件藏物、儲存、店內場景與實際搜尋。
- `src/reward.js`、`src/celebration.js`：食物頒獎、飛入收集箱與煙火。
- `src/sound.js`：原創合成配樂與音效、音量與靜音。
- `src/food-models.js`、`src/food-view.js`：原創 3D 餐點與備援算圖。
- `src/main.js`、`src/controls.js`、`src/navigation.js`、`src/ui.js`：自動入店、操作、導航與資訊卡／收集箱。
- `src/data.js`：保留的十家店資料。
