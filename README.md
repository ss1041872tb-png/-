# 中和食光 · 街角遊戲祭 v6.8

保留十家店資料、彎折巷道、汽機車、NPC、第三人稱寬鬆碰撞、主角標記、原創 3D 餐點、音效及背景配樂。街區為虛構配置；橋壽司位於永和區。

## 啟動

```sh
python -m http.server 8000 --bind 127.0.0.1
```

無外部 API 或 CDN；引擎與素材皆內附。原始碼在 `codex/zhonghe-food-explorer`，公開 GitHub Pages 部署分支為 `gh-pages`。

## 操作與玩法

- 恢復 v6.5 操控：W／↑ 前進、S／↓ 後退；A／← 左轉、D／→ 右轉，人物轉向時鏡頭同步旋轉。手機搖桿上下走路、左右轉向，斜推可邊走邊轉；放開立即停止。第三／第一人稱恢復為 6.5／5 單位／秒、轉速 1.45 rad/s。
- 滑鼠左鍵／手機右手拖曳可調整視角，滾輪／雙指縮放。第三人稱維持較遠的 36 單位（手機 ×1.18）與固定觀看高度，不恢復遇建物自動抬高或推近。第一人稱保留隱藏模型、地面眼高與碰撞保護。
- 已移除地面導引箭頭與目的地地面光圈，沒有隱藏的指引繪製或動畫；保留人物頭頂標記。小地圖選店仍切全景、顯示路線與選中招牌的青色 LED／粉色角燈；按方向鍵或推搖桿返回人物視角。
- 所有店家資料皆可預覽：點立體招牌、收集箱中的店家，或小地圖「查看店家資訊・地圖」。提供地址、特色、推薦餐點、Google 地圖照片與評論、步行導航、營業資訊／菜單與食記搜尋。查看資料不會增加闖關或收藏進度；可從資訊卡設定遊戲內目的地。
- 走到店門口自動顯示兩個小遊戲及獎勵美食。關閉提示後不會立即重開，可離開再回來，或按門口挑戰按鈕。
- 每店兩關，共二十關。第一關過關即保存，未完成的單關離開後重來。兩關完成播放煙火和慶祝音樂，美食自動放大並飛進收集箱。
- 新進度存於 `zhonghe-arcade-v6`，不清除 v1～v5 舊存檔；舊尋物進度不直接跳過新遊戲。

蜂群太空戰使用原創像素風繪圖：拖曳戰機、自動連射，擊退十二隻會編隊與俯衝的敵機，閃避敵方光彈；護盾歸零可重試。打磚塊使用球與擋板的碰撞反彈，改變擊球位置可改變角度，清掉十二塊磚過關，漏球可重新發球且保留已清除的磚。

接通水管使用單一連續的直管／彎管圖樣，沒有成對方向箭頭。點一下順時針旋轉 90°，由中間一排左側「進水口」接到右側「出水口」；藍色表示水已流到的管段。管口相接才算連通，完成後自動過關。

九宮格滑塊附清楚的目標排列，亮框表示可滑入空格的數字。按「提示下一步」會標出通往完成排列的下一張牌，不限次數；另可復原一步或重新開始。盤面由合法滑動產生，提示以分段 A* 尋路計算，不阻塞畫面。

其餘關卡包含空間解謎、音符記憶、節奏與時機、動態平衡、跳躍、釣魚與翻牌。各遊戲的過關目標與操作直接顯示在關卡內，無付費或重試次數限制。

遊戲關閉會停止動畫與計分；切換分頁不會繼續掉水或產生計分。靜音、音量、背景音樂、省電與減少動態設定保留。原創 3D 餐點示意非店家實拍。

## 測試與打包

```sh
EXPLORER_URL=http://127.0.0.1:8000 python tests/festival.py
python tests/mobile-retro.py
EXPLORER_URL=http://127.0.0.1:8000 python tests/intuitive.py
EXPLORER_URL=http://127.0.0.1:8000 python tests/navigation.py
EXPLORER_URL=http://127.0.0.1:8000 python tests/slide.py
python scripts/package.py
python scripts/standalone.py
python tests/standalone.py
EXPLORER_SINGLE=1 python tests/navigation.py
```

使用 Python Playwright 與 `/usr/bin/chromium`。驗收實際操作十店二十關，不直接呼叫 `campaign.complete()` 代替遊玩。接水測試以固定亂數重現水滴路徑，透過真實滑鼠／觸控接滿十滴；本版 tests/intuitive.py 另測人物與鏡頭同步轉向、放開即停，以及十店全角度固定俯角／距離、手機雙手搖桿／拖曳／縮放，以及桌面／手機實際接通水管與重新載入後的存檔。單檔驗收使用 tests/follow-standalone.py。

打包輸出為 `dist/zhonghe-food-explorer.zip` 與 `dist/zhonghe-food-explorer-preview.html`。單檔版內嵌模組與素材，無需伺服器；受管理瀏覽器可能禁止 file://，測試以不透明來源文件驗證。

素材與引擎授權見 CREDITS.md；禁止無理由修改 vendor 位元組。
