# 中和食光 · 街角遊戲 v5

保留十家店資料、彎折巷道、汽機車、NPC、寬鬆碰撞、主角標記、原創 3D 餐點、音效及背景配樂。街區為虛構配置；橋壽司位於永和區。

## 啟動

```sh
python -m http.server 8000 --bind 127.0.0.1
```

無外部 API 或 CDN；引擎與素材皆內附。原始碼在 `codex/zhonghe-food-explorer`，公開 GitHub Pages 部署分支為 `gh-pages`。

## 操作與玩法

- 桌面左鍵拖曳旋轉，按住滾輪拖曳上下左右平移；滾輪縮放。WASD／方向鍵移動，方向依鏡頭變化。
- 手機單指直拖平移、畫圈旋轉，自動辨識不用切換模式；雙指開合縮放，虛擬方向鍵移動人物。畫圈辨識後會撤回同一筆手勢的平移，轉為繞景旋轉；手勢不會點到店家。
- 走到店門口自動顯示兩個小遊戲及獎勵美食。關閉提示後不會立即重開，可離開再回來，或按門口挑戰按鈕。
- 每店兩關，共二十關。第一關過關即保存，未完成的單關離開後重來。兩關完成播放煙火和慶祝音樂，美食自動放大並飛進收集箱。
- 新進度存於 `zhonghe-arcade-v5`，不清除 v1～v4 舊存檔；舊尋物進度不直接跳過新遊戲。

| 遊戲 | 操作與過關條件 |
| --- | --- |
| 杯子接水滴 | 拖曳／點選杯子的位置接水，接到 10 滴；漏接可繼續，無倒數。另支援左右鍵。 |
| 星星射擊 | 點選或觸控出現在不同位置的星星標靶，命中 10 次；不是問答。 |
| 巷口井字棋 | 你是 ○，獲勝或平手過關；落敗可重試。 |
| 積木找出口 | 拖動直立積木讓路，將紅色橫塊移到右側出口；也可選積木再按方向按鈕。 |

遊戲關閉會停止動畫與計分；切換分頁不會繼續掉水或產生計分。靜音、音量、背景音樂、省電與減少動態設定保留。原創 3D 餐點示意非店家實拍。

## 測試與打包

```sh
EXPLORER_URL=http://127.0.0.1:8000 python tests/arcade.py
python scripts/package.py
python scripts/standalone.py
python tests/standalone.py
```

使用 Python Playwright 與 `/usr/bin/chromium`。驗收實際操作十店二十關，不直接呼叫 `campaign.complete()` 代替遊玩。接水測試以固定亂數重現水滴路徑，透過真實滑鼠／觸控接滿十滴；另測桌面兩種拖曳、手機直拖／畫圈、關閉清理、響應版型與儲存。

打包輸出為 `dist/zhonghe-food-explorer.zip` 與 `dist/zhonghe-food-explorer-preview.html`。單檔版內嵌模組與素材，無需伺服器；受管理瀏覽器可能禁止 file://，測試以不透明來源文件驗證。
